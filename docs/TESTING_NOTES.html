Проверки версии 3

Фактические машинные результаты находятся в reports. Проверки с людьми и защита не заменяются автоматическими тестами. История реальных вкладов обоих студентов в GitHub будет создана командой позже.

Найденные и исправленные дефекты

IDНаблюдениеИсправление
B01В ранней версии время препятствий за полсекунды паузы выросло на 0,4993 с.Игровые часы остановлены при паузе. Браузерный тест проверяет точное равенство времени до и после.
B02Удерживаемый указательный жест повторял действие после открытия окна.Сброс движения больше не сбрасывает защёлку жеста. Повтор даёт null до смены жеста.
B03Статическая проверка раннего Start.command показала открытие браузера до запуска сервера.Флаг open запускает отложенное открытие после готовности HTTP сервера. Проверка порядка, а не заявление о запуске пользователем.
B04Контакт с внешним краем движущегося дрона сервер отклонял как слишком далёкий.Радиус проверки дрона 3,3 м; отдельная регрессия в тесте 47.
B05Первая браузерная проверка получала 404 для favicon.ico.Добавлена иконка и серверный псевдоним.
B06Vosk не загрузил модель: ошибка синхронизации файловой системы, затем ошибка распаковки архива без директорий.Модель переупакована с каталогами 755; отключено лишнее дублирование в IndexedDB. Реальный Vosk распознал слово вправо, команда прошла через AudioWorklet и сдвинула персонажа.
B07Длинные надписи обрезались на табличках в 3D сцене.Шрифт вписывается в ширину; вместо длинных плавающих предупреждений используются короткие таблички на проёме и ограждении.
B08Вызов смены режима Gesture Recognizer сбрасывал количество рук с двух до одной в проверке статических кадров.Количество рук явно сохраняется при смене режима. Контрольный видеопоток распознал две руки и одновременно управлял ходьбой и обзором.
