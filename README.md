# Станция 17 — Последняя смена

Версия 4.2, локальные исправления от 12 ноября 2026 года. Жайдар — backend и AI, Аяжан — frontend и игровой мир.

В версии 4.2:
- Модель Анны оснащена полным набором анимаций захвата движения (mocap): плавная ходьба, бег и физически откалиброванный прыжок (приседание, полёт, мягкое приземление без зависания).
- Фаза шага привязана к пройденному расстоянию; исходная анимация стоп сохраняется.
- Полноценная 2D-система непрерывных коллизий с учётом радиуса персонажа, скольжения вдоль стен, круглых препятствий (турбины, цистерны, NPC) и распашной двери сейфа.
- Исправлено расположение архивных стеллажей (коллизия безопасного открытия сейфа).
- Текущие проверки и исправления описаны в docs/QA_2026-11-12.html. Старые отчёты сохранены отдельно от новых.


Исправления 12 ноября:
- Голосовая грамматика содержит «вперёд» с буквой ё: без неё локальная Vosk не распознавала команду. Движение продолжается до «стой»; звуки игры приглушаются при включённом микрофоне.
- Жест начинает действовать после короткого подтверждения; краткая потеря руки или уверенности не обрывает ходьбу. Открытая ладонь останавливает сразу; длительная потеря рук отключает движение.
- Фактическая скорость ходьбы повышена с 2,15 до 3,5 м/с, бега — с 4,6 до 6,5 м/с. Разгон и торможение одинаковы при 10–144 FPS. Правая рука следует левой ноге, левая — правой; локти сгибаются вперёд, запястья ограничены нейтральной позой.
- Сохраняется позиция при ходьбе и паузе; Esc ставит на паузу даже внутри прибора и восстанавливает его при продолжении. Исправлены достижение после подсказки и одновременная запись из нескольких вкладок.
- Исправлены масштаб текстур, повторяющиеся пятна, крепление табличек и опоры катушек; добавлены коллизии декораций, мягкие контактные тени и объединение неподвижных моделей для снижения нагрузки.

Запуск: Python 3.10+, `python3 start.py --open`, Start.command на macOS или Start.bat на Windows. Внешние Python-пакеты не нужны. Игра: http://127.0.0.1:8765/. Подробное руководство: START_HERE.html.

Анна начинает расследование в 2026 году после звонка отца, пропавшего десять лет назад. Отчёт 2074 года помогает выбрать линию клапана в 1978-м. Ремонт открывает затопленный музейный отсек в будущем. Найденная там катушка даёт ещё один вариант решения у аварийного пульта 2026 года. Сейф и разговор с Сергеем добавляют детали истории.

У Анны и Сергея анимированные 3D-модели. В зале есть насосы, трубопроводы, манометры, застеклённые окна и оборудование своей эпохи. В 2074 году работают закрытые роторы со встроенными дисплеями.

Перенос между эпохами начинается в главном зале. Возьмите запасной предохранитель, установите его в щиток справа от арки, выберите эпоху и пройдите через открывшийся портал. В финале «Возвращение» Олег выходит через портал и встречается с Анной.

До аварии 25 минут игрового времени. Часы идут в других эпохах и в головоломках. Esc, меню и скрытие вкладки останавливают их. При нуле запускается 3D сцена аварии с растущей водой, затем экран поражения. Новая попытка даёт полные 25 минут. Таймер рассчитывает сервер; клиент не может прислать дополнительное время.

WASD — движение; мышь — обзор после одного щелчка; V — первое/третье лицо; Shift — бег; E — взаимодействие; R — щиток портала поблизости; J — журнал; F — проверка головоломки; M — голос; G — две руки. Левая рука двигает персонажа, правая вращает камеру; роли меняются под видео. Голосовые команды камеры сохранены. Модели Vosk и MediaPipe входят в комплект и работают локально.

Все эпохи доступны в бесплатной части. Собственный платёжный стенд открывает финальную главу за 990 тенге без реального списания. Сервер проверяет право доступа и подписанные события.

Сохранения и подпись создаются в data/. Архив поставляется с чистым профилем. В существующем профиле версии 4 сохраняются ремонт, записи, таймер, открытый доступ и настройки.

Проверки без браузера: `npm test` (Python + Node). Отдельно: `python3 tests/test_game.py`, `npm run test:controls`, `npm run test:clock`, `npm run test:locomotion`. Для браузерного маршрута: `npm install`, `npx playwright install chromium`, `npm run test:browser` при работающем сервере. Для дополнительных браузерных проверок: `npm run test:regressions`, `npm run test:voice`, `npm run test:gestures`, `npm run test:animation`. Они создают отдельные профили; запускайте сервер с `--db /tmp/station17-qa/game.sqlite3`, чтобы изолировать тестовые данные. На macOS можно задать `STATION_BROWSER` путём к исполняемому файлу Chrome; `STATION_URL` меняет адрес сервера. Поставку можно запустить без Node и npm.

Результаты контролируемых тестов находятся в reports. Живые тесты с тремя внешними людьми, личные вклады обоих студентов в закрытом GitHub и защита пока не выполнены. Репозиторий отложен по просьбе команды.
